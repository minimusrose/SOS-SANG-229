# SOS Sang 229

Plateforme MVP d'alerte donneur de sang (Hackathon Cursor Bénin).

Stack prévue : React + Tailwind (frontend), FastAPI (backend), PostgreSQL + PostGIS, Twilio SMS.

Ce dépôt vient d'être initialisé. La structure monorepo sera ajoutée via la PR `init/setup-projet`.

## Sécurité

Ne jamais committer de secrets (`.env`), ni de données réelles de donneurs (téléphone, GPS, groupe sanguin).
